Read https://github.com/ZeroRank-AI/zerorank/tree/main/data and use the help desk dataset to find patterns in product mentions across engines and markets. Build a chart of the clearest pattern and label it with the study dates and answer counts.

## Help desk software across five markets

We asked the same English-language buyer questions in ChatGPT and Google AI Overviews. The questions range from choosing a shared inbox to requiring regional data storage. You can compare how often each engine mentioned a tracked product, inspect the underlying question, or explore which source domains appeared in answers.
